# shapebyte

Shape digests and byte fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/shapebyte/

## Install / run

```bash
git clone https://github.com/theworker02/shapebyte.git
cd shapebyte
node src/cli.js
node --test
```
